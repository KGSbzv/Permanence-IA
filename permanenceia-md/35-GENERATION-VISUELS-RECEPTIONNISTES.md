# Génération visuelle des réceptionnistes IA

## Objectif

Créer une identité visuelle originale pour chaque réceptionniste ou agent IA, visible sur la page principale, les cartes d’agents, les pages packages, les landing pages sectorielles, le portail client et les supports commerciaux.

## Visuels à générer

- Portrait principal de l’agent.
- Avatar circulaire pour le hero.
- Carte agent avec gradient et icône de fonction.
- Version claire et version sombre.
- Version desktop, tablette et mobile.
- Illustration de l’agent en interaction avec un CRM, un agenda ou une conversation.
- Miniature pour le catalogue des agents.
- Visuel de statut : disponible, configuration, bêta ou sur mesure.

## Règles créatives

- Ne pas copier les portraits, compositions ou illustrations de Vendasta.
- Utiliser des personnages originaux et cohérents.
- Éviter les stéréotypes liés au métier, au genre ou à l’origine.
- Montrer une assistance professionnelle, pas une personne réelle présentée comme employée.
- Ajouter une mention visible « Agent IA ».
- Utiliser une palette PermanenceIA : bleu nuit, turquoise, violet, bleu clair, vert et accents corail.

## Réceptionniste IA

La réceptionniste IA doit être présentée comme l’agent qui accueille, comprend la demande, collecte les informations, crée un lead, propose un rappel planifié ou un rendez-vous lorsque la capacité est réellement disponible.

Elle ne doit pas être représentée avec un téléphone ou un numéro public, conformément à la règle zéro numéro. Le visuel peut montrer une interface de conversation, un formulaire callback, un agenda ou une fiche CRM.

## Prompt visuel de base

« Portrait original d’un agent IA de réception pour une plateforme SaaS B2B, style premium et chaleureux, cadrage poitrine, expression professionnelle, arrière-plan dégradé bleu nuit vers turquoise et violet, lumière douce, carte graphique moderne, aucun logo tiers, aucun numéro de téléphone, aucun texte illisible, aucun faux témoignage, petite indication visuelle Agent IA, rendu cohérent avec une interface SaaS haut de gamme. »

## Formats

- Hero : 1200 × 900.
- Carte agent : 800 × 1000.
- Avatar : 512 × 512.
- Mobile : 900 × 1200.
- Illustration dashboard : 1600 × 1000.
- Open Graph : 1200 × 630.

Chaque image doit être optimisée en WebP/AVIF, avec texte alternatif, poids contrôlé et version de remplacement accessible.
