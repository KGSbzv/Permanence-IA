# Catalogue des agents IA

- Agent Capture : reçoit les demandes web et crée les leads.
- Agent Commercial : rappelle aux créneaux choisis, qualifie et suit.
- Agent Support : rappelle les clients et gère les tickets.
- Agent Agenda : propose et confirme des rendez-vous.
- Agent Réputation : prépare les demandes d’avis, sous validation.
- Agent Relance : réactive les prospects autorisés.
- Agent Contenu : prépare des contenus soumis à validation.
- Agent Données : produit des rapports opérationnels.
- Agent SEO local : propose des optimisations vérifiables.
- Agent personnalisé : configuration sur devis.
