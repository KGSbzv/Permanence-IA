# Schémas fonctionnels

## Schéma callback

Page ou promotion → formulaire → consentement → CRM → disponibilité → rappel planifié → agent IA → résultat → suivi ou escalade.

## Schéma CRM

Lead → qualification → offre → rappel ou rendez-vous → opportunité → client → support → rétention → reporting.

## Schéma agents

Agent Capture alimente le CRM. Agent Commercial convertit. Agent Agenda organise. Agent Support résout. Agent Réputation et Agent Relance engagent selon les autorisations. Agent Données mesure.

## Règle zéro numéro

Tous les schémas doivent montrer un formulaire, un agenda ou un ticket à la place d’un numéro public.
