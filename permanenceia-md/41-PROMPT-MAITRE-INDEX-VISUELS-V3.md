# Prompt maître — index et génération visuelle V3

Audite l’état réel du projet avant toute modification. Mets à jour la page principale de PermanenceIA pour présenter une équipe d’agents IA spécialisés, avec une identité visuelle originale, des portraits générés, des cartes d’agents, des schémas de parcours et des mockups de portail client.

La page doit présenter : hero orienté résultats, CTA Commencer gratuitement, Connexion, Inscription, Demander une démonstration et Demander un rappel ; section définition des agents ; catalogue d’agents ; parcours Attract/Convert/Engage/Measure ; secteurs ; packages ; comparaison ; portail client ; intégrations ; FAQ ; CTA final.

Génère les visuels de la Réceptionniste IA et des autres agents dans un style cohérent, original et professionnel. Ne copie pas Vendasta. Ne montre aucun numéro public. Le téléphone fourni par un prospect existe uniquement dans une demande de rappel soumise avec consentement.

Configure le plan Gratuit sans carte et sans engagement uniquement si le billing, les limites et l’onboarding sont réellement opérationnels. Vérifie login, inscription, récupération, rôles, packages, entitlements, CRM, callbacks, support, reporting, mobile, bilingue, accessibilité, SEO et absence de doublons.

Ne publie pas un chiffre, une preuve sociale, une fonctionnalité, un tarif, un visuel ou une promesse non vérifiés. Produis un rapport de validation avant mise en production.
